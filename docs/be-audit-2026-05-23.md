## 1. Methodology

Probe pipeline:

```bash
# 1. Login admin cookie
curl -sS -c /tmp/admin.cookie -X POST \
  -H 'Content-Type: application/json' \
  -d '{"email":"admin@rexer.ai","password":"<dev-password>"}' \
  https://rexerai.tekupsoftware.com/v1/auth/login
# → role=admin, email=admin@rexer.ai ✅

# 2. Probe endpoint với cookie:
curl -s -b /tmp/admin.cookie -o /dev/null -w '%{http_code}\n' \
  https://rexerai.tekupsoftware.com/v1/<path>
```

Status code interpretation:
- **200** = endpoint exists + admin can access
- **400** = endpoint exists + body validation failed (POST/PATCH với `{}`)
- **403** = endpoint exists + admin không có quyền (brand-only role-gated)
- **404** = endpoint **truly missing**
- **401** = auth middleware reject trước routing → KHÔNG distinguish được
  (no cookie path)

## 4. ❌ Truly missing — cần BE ship

### 4.1 `GET /admin/users` (list)

```bash
curl -s -b admin.cookie https://rexerai.tekupsoftware.com/v1/admin/users \
  -o /dev/null -w '%{http_code}\n'
# → 404
```

- **POST /admin/users** trả 400 với `{}` (endpoint exists, cần body)
- **GET /admin/users** trả **404** → route chưa register
- **Impact**: `/admin/users` page không list được. Hiện đang fallback
  `rexerApi.clients` + filter — không đúng semantic.
- **Effort**: ~2h (handler + query + pagination)
- **Reference**: `be-todo.md` P1.1

### 4.2 `views_by_day` trên `BlockBreakdownRow`

Probe `/portal/templates/{id}/breakdown` trả **200** với rows empty
(template chưa có analytics events). Không verify được field
`views_by_day` đã ship hay chưa. **Cần BE confirm**:

```bash
curl -s -b admin.cookie \
  "https://rexerai.tekupsoftware.com/v1/portal/templates/<id>/breakdown" | jq '.[0] | keys'
```

Field cần (gắn vào schema `BlockBreakdownRow`):

```ts
{
  block_id: string,
  block_type: string,
  views: number,
  clicks: number,
  // ... existing fields ...
  views_by_day: number[]   // ← NEW: oldest → newest, length = range_days
}
```

**Impact**: `/portal/landing-pages/[id]/analytics` sparkline đang generate
mock deterministic từ block_id hash. UI sẽ auto-live khi BE thêm field.

**Effort**: 3-4h (query group-by-day, fill missing days với 0).

### 4.3 `/v1/templates` query params

Endpoint `GET /v1/templates` hiện return full list không có query support.
FE đang filter/sort/paginate client-side trên trang `/admin/templates`
(landing page template list).

**Cần BE ship**:

```
GET /v1/templates?q=&category=&status=&sort=&page=&limit=
```

**Shape mong đợi** (giống `CanvasTemplateListResponse`):

```ts

  items: Template[],
  page: number,
  limit: number,
  total: number,
  total_pages: number

```

**Effort**: 2h.

## 8. Probe script (BE QA chạy verify)

```bash
#!/usr/bin/env bash
# verify-be.sh — BE QA chạy với admin cookie để verify mọi endpoint
BASE="https://rexerai.tekupsoftware.com/v1"
CK=/tmp/admin.cookie

# Login
curl -sS -c "$CK" -X POST -H 'Content-Type: application/json' \
  -d '{"email":"admin@rexer.ai","password":"<dev-password>"}' \
  "${BASE}/auth/login" | jq -r '.user.role'
# Expected: "admin"

# Group A — Portal GET (must be 200)
for p in /portal/dashboard/summary /portal/templates /portal/templates/library \
  /portal/comments /portal/me /portal/ads/channels /portal/ads/campaigns \
  /portal/curate/events /portal/curate/interaction-types /portal/notifications \
  /portal/activity /saved-blocks; do
  code=$(curl -s -b "$CK" -o /dev/null -w '%{http_code}' "${BASE}${p}")
  printf "%-5s GET %s\n" "$code" "$p"
done

# Group B — Brand-only (admin trả 403 → endpoint exists, brand cookie test riêng)
for p in /portal/me/client /portal/me/members; do
  code=$(curl -s -b "$CK" -o /dev/null -w '%{http_code}' "${BASE}${p}")
  printf "%-5s GET %s  (403=brand-only, expected)\n" "$code" "$p"
done

# Group C — POST với empty body (400=exists+validation, 404=missing)
for p in /portal/workspaces /portal/templates /portal/me/members /admin/users; do
  code=$(curl -s -b "$CK" -X POST -H 'Content-Type: application/json' -d '{}' \
    -o /dev/null -w '%{http_code}' "${BASE}${p}")
  printf "%-5s POST %s  (400=ok, 404=missing)\n" "$code" "$p"
done

# Group D — Confirmed missing
code=$(curl -s -b "$CK" -o /dev/null -w '%{http_code}' "${BASE}/admin/users")
printf "%-5s GET /admin/users  (404=truly missing)\n" "$code"
```
